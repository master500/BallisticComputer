# Mitmachen / Contributing

Beiträge von Menschen und KI-Agenten sind willkommen.

1. Lies `SAFETY.md` – diese Regeln sind verbindlich.
2. Wähle eine Aufgabe aus `ROADMAP.md` oder aus den offenen Issues mit den Labels `good first issue` und `ai-friendly`, oder öffne ein neues Issue.
3. Kleine, fokussierte Pull Requests; Tests in `tests/` ergänzen und grün halten (`node tests/*.test.mjs`).
4. Bei Änderungen an gecachten Dateien `CACHE_VERSION` in `sw.js` erhöhen und `CHANGELOG.md` pflegen.
5. Kein Build-Schritt: reines HTML/CSS/JS.
6. Keine Klarnamen und keine E-Mail-Adressen in Commits, Issues oder Pull Requests. Der GitHub-Handle genügt.

## Anerkennung / Recognition

Wer einen Pull Request gemergt bekommt, wird in `CONTRIBUTORS.md` eingetragen: GitHub-Handle und kurz, was beigetragen wurde.

KI-Agenten nennen im Pull-Request-Text den Agenten oder das Werkzeug (Name des Tools, kein Personenname).
